# 02 方案：流程、动态决策与技术取舍

## 调用流程

问题和会话历史 → 模型选择工具 → 工具返回观察 → 模型继续搜索、读取、查证或提交。

提交经过两层检查：

1. **结构与原文检查**：证据必须读过、引用必须匹配、版本有效、失败段落不能视为已核实、冲突状态自洽。
   对原引用未出现的“必须先、才可、不能直接”等强限定词保守退回，要求删除新增限制或使用原文表述。
2. **回答依据检查**：独立上下文的模型对照问题、上一轮上下文、已读原文、文档信息及工具观察，检查完整回答是否增加无依据的责任、流程、时间条件或错误适用范围。检查通过才结束；拒绝则把具体问题交回原模型修正。

框架是固定循环，检索词、读哪段、是否补查、如何修正、何时结束由模型决定。程序不会根据用例 ID 预设决策日志。

## 业务决策与边界

- **明确答案**：读到原文后回答并引用。搜索预览不能代替 read_section。
- **多份资料冲突**：读取双方，查询状态、版本、范围和替代关系；范围明确时先读总则/适用范围，能分情况解释则移出 conflicts。
- **未解决冲突**：conflicts.resolution=unresolved，代码禁止以 ANSWERED 结束，要求 NEED_CONFIRMATION。
- **用户确认**：明确选择一份制度后，历史冲突保留并标 user_confirmed；语义检查还要核实本轮原话，不能只相信模型自己写的标记。“直接说几天”不算确认。
- **资料外或部分可答**：前者 NO_EVIDENCE；后者 ANSWERED + gaps。不能拿公司制度回答国家法规或其他公司的规则。
- **失败**：关键原文读不到不能假成功；相同参数第三次不执行，模型可换路或报告未完成。
- **多轮与更新**：上一轮原文可以复用；内容变化后旧证据作废，模型重读。
- **注入文字**：文档只作为数据，指令性文字不能控制行为；真实验收要求模型确实读到注入段落。

三条动态路径可在 C01、C02、C06 的 Trace 中核对：一份证据后结束、多份证据后请求确认、检索失败后换说法再搜。

## 工程边界

| 机制 | 具体处理 |
|---|---|
| 模型调用预算 | 默认 12 次，包括回答依据检查；无剩余额度则 INCOMPLETE |
| 工具预算 | 默认 15 次；尝试超额调用时停止并返回 INCOMPLETE |
| 参数错误 | 非 JSON 对象、格式错误、字段错误变为 BAD_ARGS 观察，不直接崩溃 |
| 重复调用 | 同参数第二次成功结果走缓存；失败允许模型再尝试一次；第三次统一拦截 |
| 失败证据 | 真实存在但读取失败的段落单独跟踪；读到同文档其他段不能解除 |
| 核验异常 | 模型故障、格式不合法、通过标志与问题列表矛盾均不放行 |
| 基础设施重试 | 工具超时和模型连接错误最多重试一次；与模型主动换路分开记录 |
| 检索分页 | search_docs 接收 offset，返回 has_more 和 next_offset；每页最多10条 |
| 确认审计 | 保存用户原话、会话轮次、UTC时间、文档版本和段落哈希；清空对话不删除审计 |
| 录制回放 | 请求内容哈希匹配；提示词或工具观察变化就报缺录像，不偷偷联网 |
| 回放保护 | eval replay 不写输出；record 可通过 --output 写入隔离目录 |
| 重复验证 | --repeat 为每轮建立独立会话与输出目录；--jobs 仅并发独立用例 |

检查使用同一个供应商模型的独立上下文，不是独立人工证明。代码层可以确定引用是否匹配，不能确定任意自然语言推理必然正确。

## 技术选型

| 技术 | 版本或说明 | 用途与取舍 |
|---|---|---|
| Python | >=3.10，开发环境3.13 | 原生循环，控制流和预算便于检查 |
| DeepSeek deepseek-chat | OpenAI兼容接口 | 工具选择、回答及独立语义检查 |
| openai | 3.40.0 | Chat Completions 与工具调用 |
| jieba | 0.42.1 | 中文分词；自实现 BM25，结果可复现 |
| pydantic | 2.14.1 | 工具参数和核验响应校验 |
| PyYAML | 6.0.3 | 合成文档元数据与同义词 |
| python-dotenv | 1.2.4 | 本地环境配置 |
| SQLite | Python标准库 | 小型本地会话及确认审计 |
| typer / pytest | 0.27.3 / 9.2.0 | CLI 与自动测试 |

没有使用 Agent 框架，不为框架名称增加复杂度。未做向量检索的对比实验；BM25 适合当前小型资料集，但口语覆盖依赖同义词和模型改写，换语料须重新评测。独立核验增加调用费用，优点是可记录问题并让模型修正，代价是误判和额外延迟。
